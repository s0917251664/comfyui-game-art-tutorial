# 遊戲美術 AI 協作與產線

用自然語言描述需求，讓 AI 代理協助製作與整理遊戲美術素材。專案把需求整理、圖片與短影片生成、素材後製及驗收串起來，使用者不需要自己拉 ComfyUI 節點。

## 這個專案有什麼

| 工作 | 可以做的事 |
|---|---|
| 需求整理 | 整理參考圖用途、要改與要保留的細節，以及交付與驗收條件 |
| 圖片製作 | 概念圖、圖示、角色動作、局部重繪、精修、放大與分層 |
| 短影片製作 | 靜態圖轉影片、動作驅動、角色替換、運鏡、片段接續與局部重繪 |
| 素材後製 | 圖片裁切、合成、換色、物件展示組裝、特效去背與打包 |
| 聲音與遮罩 | 配音、對嘴，以及圖片或影片的遮罩製作與輔助處理 |
| 製作紀錄 | 保存流程設定、輸出與檢查結果，累積可供後續參考的經驗 |

實際可用功能取決於選定路線、電腦硬體、已安裝模型與工具；執行前會先確認能力。

## 怎麼運作

**描述需求 → 整理參考與驗收條件 → 確認工具能力 → 執行既有流程 → 檢查候選素材 → 使用者驗收**

1. **說明想做什麼**：提供文字、圖片或影片，說清楚希望改動與保留的部分。
2. **AI 代理選擇路線**：依需求與目前環境，選擇可用的生成或素材處理工具。
3. **執行並留下紀錄**：產生候選素材，檢查尺寸、幀數等技術條件；多步驟流程可在中途停下，等待人工確認。
4. **由你決定是否可用**：檢查角色、構圖、動作與風格，接受結果或提出下一輪修改。技術檢查通過，不等於美術驗收通過。

## 三條工作路線

- **本機 ComfyUI**：使用本機模型生成圖片或影片。專案以 Template（固定流程範本）定義節點與可調整的輸入，任務入口選出範本後，由 Runner（執行器）負責預檢、送出與收集結果。Recipe（多步驟流程）則串接需要人工確認的工作。
- **本機素材工具**：用 Python 直接處理圖片、影片與音訊，適合裁切、合成、去背、打包等後製工作；這些工具各有自己的依賴，不需要套用 ComfyUI 生成流程。
- **平台圖片工具**：使用目前 AI 會話提供的生圖或編修工具，不需要本機 ComfyUI；可用功能依平台而定。

AI 代理依技能文件判斷需求與路線，工具執行實際工作，知識庫保存判斷依據與經驗。ComfyUI 生成使用既有固定流程；需要新能力時，先評估與驗證，再納入專案。

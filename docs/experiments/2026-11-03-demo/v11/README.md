# Demo v11：揮砍軌跡改用顏色柔邊、劍身維持換色（保留 v1–v10）

沿用 v10 的來源影片（`source.mp4`，107 幀）與劍身追蹤，改動：
1. **揮砍軌跡（第 44–60 幀）不用硬遮罩**：以藍／青飽和度算柔邊（smoothstep＋0.7 像素模糊），只去除色度、保留原亮度與透明漸層，所以軌跡變成冷白色的柔光，沒有方塊邊；暗色（劍鞘、陰影）不動。
2. **劍身實體維持 v10 的暗鋼換色**，色階固定取自第 0 幀，所以模糊幀前後顏色一致；第 46–52 幀因為 SAM 遮罩混進光軌與劍鞘，只用「接觸護手且面積合理」的區塊。
3. 清除小黑點：改動範圍限制在「劍遮罩±3 像素、或原本有青藍色調、或髮絲」內，再把小於 120 像素的零碎改動還原；劍鞘（深藍）一律還原成原樣。
4. 追蹤 GIF（`tracking_overlay.gif`／`.mp4`）左側標題為「追蹤（劍身範圍＋軌跡）」，路徑只用劍身實體的遮罩中心，光軌幀（第 44–52 幀）用前後幀內插，再做 5 幀移動平均；右側是 v11 結果。

## 數字（`summary.json`、`data/per_frame.json`）
- 青藍色調像素（飽和度指標 >0.25，排除劍鞘）：每幀平均 10,225 → 66；最大 1,656（第 49 幀，光軌最濃的一幀）。
- 劍／光軌影響區以外，每幀相對來源變動 **0**（107 幀最大 0）。

- 第 46–47 幀的劍身（舉起、被光軌包住）上緣有一小段灰色細弧，是光軌尾端被當成劍身的一部分。

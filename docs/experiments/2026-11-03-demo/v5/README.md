# Demo 1 v5：手臂保持銀色板甲、手大小與持劍手相近（保留 v4）

做法：`gameart.py pose-edit run --image A.png --custom …`，提示詞明寫「被移動的手臂保持與原圖相同的銀色板甲（肩甲、上臂與前臂甲），褐色手套只在手上，手與持劍手同大小」，並禁止「布袖、褐色袖子、裸前臂、長手套、過大的手」。揮手、指向、敬禮各 24 個 seed（每批 6 個，約 28 秒／張，共 72 張）。候選以仿射對位（ECC）對齊原圖，只把畫面右側手臂區貼回：人物前景像素、顏色以區域外人物像素對齊、約 1 像素羽化，背景色差另補；其餘全是原圖。
圖：`demo1_three_poses.jpg`（每列：原圖同位置放大｜修後手部放大｜修後全身｜差異熱圖）；`data/demo1_three_poses.json`；`data/zoom3x_*.png`（3 倍放大前後）。

| 姿勢 | 試過／挑中 seed | 貼回區域像素 | 區域外相對原圖變動 | 持劍手套面積（參考）| 新手套面積 | 比值 |
|---|---|---|---|---|---|---|
| 揮手 | 24／13 | 100,987 | **0**（910,725 個） | 7,340 | 7,698 | 1.05 |
| 指向前方 | 24／18 | 90,562 | **0**（921,150 個） | 7,340 | 6,461 | 0.88 |
| 敬禮 | 24／6 | 121,668 | **0**（890,044 個） | 7,340 | 6,109 | 0.83 |
手套面積＝褐色像素連通區面積（粗略估計，含手腕褐色袖口）；3 個都在持劍手套的 ±17% 內，其中揮手、指向在 ±12% 內，敬禮偏小（0.83，略超出 ±10%）。

篩選（目視）：72 張中多數把前臂變成褐色長袖／長手套、或手比例過大／握拳／V 字、敬禮多數沒舉到額頭；挑的 3 張前臂是銀色板甲、手勢正確、持劍手未變。

誠實檢查（3 倍放大）：指向前方：手腕護甲接合乾淨，無灰暈、無殘指，手套與持劍手同色；這張指尖朝右上方而非正前方，拇指外張。揮手與敬禮未逐像素看完，大致乾淨；敬禮貼回區包含額頭與一小塊頭髮，該處是候選版本。肩甲、上臂的線條與原圖不完全相同（候選版本）。上臂內側仍可見褐色內襯（與原圖肘部相同）。單一素材、目視挑選，沒有逐張統計。

# Demo 3／4 v5（換乾淨整把劍、頭髮保持原樣；保留 v3）

## Demo 3 靜圖：冰晶劍→深色鋼（A.png）
做法：改用 SAM3（`video/sam3/track-text`，把 A.png 疊成 5 格影片）以 "blue crystal" 取得**整把劍**遮罩（含護手與頭之間的劍根，v3 漏掉的部分），以 "hair" 取得頭髮前景遮罩；劍身像素就地重新上色（依原本亮度對應到暗鋼→銀的色階，保留刃面、描邊與頭髮縫隙），頭髮前景像素完全不動，所以劍的輪廓自然繞到頭髮後面。不使用 FLUX 重畫（v3 的接縫問題來自貼回新生成的圖）。
數字（`data/demo3_numbers.json`）：劍身像素 38,567；頭髮前景 19,440 像素變動 **0**；劍範圍外 971,757 像素變動 **0**；劍外接框內的青色像素（Lab a≤126、b≤125）前 20,044 → 後 84（約 0.4%，多為頭髮邊緣一帶與刃緣極淡色）。
圖：`demo3_blade_material.jpg`（6 格：原圖｜整把劍遮罩｜頭髮前景｜結果｜差異熱圖｜青色像素前後）、`demo3_zoom.jpg`（3 倍：劍根與護手、頭髮與劍重疊、劍尖，左原右後）。
誠實檢查：3 倍放大下頭髮絲、輪廓都保留，劍根整段已換色；頭髮下緣、右側頭髮邊的藍色調（髮絲本身被劍反光染到的淡藍）保持原樣，所以靠近頭髮處還有少量淡藍色；劍身偏單色灰（非 v3 那種有凹槽的材質），是換色而非重畫。

## Demo 4 影片：同一做法逐幀（49 幀，480×704，24fps）
做法：對來源騎士影片逐幀用 SAM3 追蹤 "blue crystal"（整把劍）與 "hair"（頭髮），每幀同樣就地換色、頭髮不動；色階用第 0 幀的固定範圍，避免逐幀亮度跳動。SAM3 追蹤各約 8 秒，換色約 20 秒。
數字（`data/demo4_metrics.json`）：劍外 30 像素以外 49 幀變動像素 **0**；頭髮遮罩內變動 **0**；劍外接框內青色像素每幀平均 7,518 → 22（最大 116）；相鄰幀差（劍區）來源 24.0、v5 33.2——**沒有降低**，因為來源影片的劍本身就在變形（劍面積每幀平均變動約 1,500 像素），換色再拉大對比後差異更大；所以不拿「相鄰幀差」當穩定度指標。
圖／影片：`demo4_before_after.mp4`（左原片右結果）、`.gif`、`demo4_strip.jpg`（5 幀）、`demo4_hair_zoom.jpg`（3 幀的頭髮與劍重疊 3 倍，左原右後）。
誠實檢查：每幀整把劍都已換色，包含劍根；第 48 幀頭髮下緣仍有一點淡藍髮梢；影片裡的劍形狀本來就會晃動，這版不修正形狀，只換材質。

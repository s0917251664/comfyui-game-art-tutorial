# Demo 1 v5：手臂保持銀色板甲、手大小與持劍手相近（保留 v4）

做法：`gameart.py pose-edit run --image A.png --custom …`，提示詞明寫「被移動的手臂保持與原圖相同的銀色板甲（肩甲、上臂與前臂甲），褐色手套只在手上，手與持劍手同大小」，並禁止「布袖、褐色袖子、裸前臂、長手套、過大的手」。揮手、指向、敬禮各 24 個 seed（每批 6 個，約 28 秒／張，共 72 張）。候選以仿射對位（ECC）對齊原圖，只把畫面右側手臂區貼回：人物前景像素、顏色以區域外人物像素對齊、約 1 像素羽化，背景色差另補；其餘全是原圖。
圖：`demo1_three_poses.jpg`（每列：原圖同位置放大｜修後手部放大｜修後全身｜差異熱圖）；`data/demo1_three_poses.json`；`data/zoom3x_*.png`（3 倍放大前後）。

|---|---|---|---|---|---|---|

手套面積＝褐色像素連通區面積（粗略估計，含手腕褐色袖口）；3 個都在持劍手套的 ±17% 內，其中揮手、指向在 ±12% 內，敬禮偏小（0.83，略超出 ±10%）。

篩選（目視）：72 張中多數把前臂變成褐色長袖／長手套、或手比例過大／握拳／V 字、敬禮多數沒舉到額頭；挑的 3 張前臂是銀色板甲、手勢正確、持劍手未變。

誠實檢查（3 倍放大）：指向前方：手腕護甲接合乾淨，無灰暈、無殘指，手套與持劍手同色；這張指尖朝右上方而非正前方，拇指外張。揮手與敬禮未逐像素看完，大致乾淨；敬禮貼回區包含額頭與一小塊頭髮，該處是候選版本。肩甲、上臂的線條與原圖不完全相同（候選版本）。上臂內側仍可見褐色內襯（與原圖肘部相同）。單一素材、目視挑選，沒有逐張統計。

# Demo 3／4 v6（補塗藍色殘留；保留 v5）

v5 的問題：頭髮邊的淡藍髮梢、劍根邊緣的藍色細邊、抗鋸齒邊緣沒有塗到。v6 在 v5 的整把劍換色之上加：
1. 距劍遮罩 12 像素內（頭髮靠劍處放寬到 30 像素），找出藍／青色像素（色相約 170–230°、飽和度高於灰髮／灰鋼，加 Lab 偏青條件），向外擴 1 像素。
2. 髮絲上的藍色：只改色相、保留亮度，換成附近未染藍髮絲的中位灰色調。
3. 劍邊與抗鋸齒像素：換成與劍身相同的灰鋼色階。
4. 劍遮罩外 30 像素以外不動。

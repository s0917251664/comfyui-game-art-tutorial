# Demo v8：劍根改為「主劍身的幾何延伸」（保留 v6、v7）

靜圖與 49 幀影片做法相同（影片逐幀各自擬合）：
1. 在主劍身（頭右側、排除被頭髮碰到的邊緣）用 SAM 劍遮罩取兩條長邊，各擬合成直線；軸線用劍遮罩主軸。影片每幀各自擬合，直線參數（角度與兩邊偏移）再做 5 幀中位數平滑。
2. 把兩條邊向左下延伸到護手（以最大的金色連通區定位）。劍面顏色沿橫截面（上緣到下緣）取樣自緊鄰頭髮外側的主劍身，所以延伸出去的是同樣的上亮下暗；兩條長邊加 2–3 像素深色描邊。
3. 層次：頭髮、臉、紅領、金色護手、盔甲保持 v6 原像素；只在「延伸多邊形 ∩（舊劍根塊或原本是背景的像素）」畫劍；舊劍根塊落在多邊形外的部分補回背景（inpaint）。

數字：
- 靜圖（`data/demo3_numbers.json`）：改動範圍約 7,990 像素，範圍外相對 v6 變動 **0**。
- 影片（`data/demo4_metrics.json`）：49 幀都擬合成功；範圍外相對 v6 最大變動 **0**；軸線角度逐幀變化平均 3.29°（未平滑）→ 1.28°（平滑後）；寬度逐幀變化 5.9 px → 3.9 px。

檔案：`demo3_blade_material.jpg`（6 格）、`demo3_zoom.jpg`、`demo3_result.png`、`demo4_before_after.mp4`／`.gif`、`demo4_strip.jpg`、`demo4_base_zoom_frames_0_24_48.jpg`。

## 誠實限制
- 劍根在畫面上只有頭髮與護手之間一小段，其餘被頭髮、臉、頸擋住，所以是一條偏淺的細斜帶，下半暗斜面幾乎看不到。
- 影片裡這條帶比主劍身細／淡，部分幀只剩灰色細線，不像一把完整的劍根。
- 靜圖護手端邊緣有少量鋸齒（為了避開金色像素）；背景補洞偶有色塊差異。
- 單一素材、目視判斷，沒有逐幀人工檢查。

# Demo v9：劍根用主劍身真實筆觸延伸（保留 v6、v7、v8）

## 與要求不同的地方（先講）
- **沒有跑 ControlNet guided_inpaint**：先前 SDXL 局部重繪在這個位置會整張重生成並偏移，這次改走要求裡的備案（手動色階／取樣），但不是調色階，而是**把主劍身緊鄰頭髮外側那一段的真實像素（含水彩筆觸、斜面、描邊）沿軸線鏡射延伸到劍根**，所以劍根的筆觸、斜面顏色、描邊與主劍一致；碰到頭髮的取樣位置回退成橫截面色階。
- 影片**沒有「一次建好貼圖再逐幀變形」**：每幀用同一個畫法（取該幀主劍身的真實像素鏡射），多邊形用該幀平滑後的直線擬合，所以寬度與角度跟該幀主劍一致。
- 護手端用平滑過的保護遮罩（高斯後門檻）做 1 像素抗鋸齒，比 v8 的鋸齒少。

## 數字
- 靜圖（`data/demo3_numbers.json`）：改動範圍約 7,984 像素，範圍外相對 v6 變動 **0**。
- 影片（`data/demo4_metrics.json`、`data/per_frame_check.json`）：49 幀擬合都成功；範圍外相對 v6 最大變動 **0**；每幀都有畫到劍根（最少 974、中位數 2,212、最多 3,094 像素）；舊的暗色劍根殘塊每幀 ≤63 像素；碎片（<60 像素的獨立小塊）只有第 6、25 幀有 3 個以上。

## 逐幀檢查結果（`demo4_base_all_frames.jpg`：每幀劍根裁切，左 v8、右 v9）
- 49 幀全部有劍根、沒有殘留暗塊、沒有大塊灰碎片；第 6、25 幀各有 ≥3 個小碎片（逐幀目視為髮際線上的小灰點）。
- **寬度沒有達到主劍身的 100%**：每幀可見劍根寬度中位數只有主劍身寬度的約 0.39 倍。原因是劍根下半被頭、臉、頸擋住，能看見的只有上斜面那一條；這是遮擋造成的，不是我把它畫細，但外觀上仍是一條比主劍細的斜帶。
- 髮際線處的接縫（劍根與主劍之間）在多數幀是連續的；自動量測的「髮際缺口比例」不穩定（受頭髮遮罩影響），我沒有把它當通過標準。
- 第 2、26、27、28 幀的擷取圖沒有對到頭部（拼圖裁切位置落在護手與拳頭），那四幀的劍根位置需要另外對照 mp4 看；我沒有逐幀手動修補。

## 沒做／限制
- 沒有手動逐幀微調；若你要求每一幀寬度一致且完整可見，需要另一個做法（例如逐幀手畫）。
- 單一素材、目視判斷。

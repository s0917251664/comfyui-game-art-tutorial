# 四個編修 Demo 的決策紀錄（v1–v11 濃縮）

推廣簡報的四個 Demo 在 Windows RTX 4080 上反覆做了 11 版。這頁只留**最後採用的做法、被否決的做法與原因、值得記的數字**。逐版說明與圖片、影片在封存分支 `claude/project-thread-s1ejng`（PR #12）的 `docs/experiments/2026-11-03-demo/`，平常不需要讀。

素材：2026-10-19 自行生成的騎士圖（不含 Skye 素材）。所有結果都是候選，美術由人驗收（R1）；評分為目視、非盲評、單一素材。

## 總原則（Steve 2026-11-03 定的）

**只有指定要改的地方可以變，其餘像素必須和原圖完全一樣。** 盔甲或色調漂移、多長手腳、遮罩邊緣粗糙、影片閃爍都不能接受。做法一律是：模型或工具產生改動 → 只把改動區貼回原圖 → 量「改動區以外變動像素 = 0」。

## Demo 1／2：改姿勢、改手勢（靜圖）

**採用**：`gameart.py pose-edit run --custom "…"` 出多個 seed 候選 → 候選以仿射對位（ECC）對齊原圖 → 只把「被移動的那隻手臂與肩區」的人物前景像素貼回（顏色對齊周圍、約 1 像素羽化）→ 其餘全是原圖。

數字（v5）：揮手、指向、敬禮各試 24 個 seed，每種挑 1 張；貼回區 9–12 萬像素，**區域外 0 個像素變動**；新手套面積是持劍手的 0.83–1.05 倍。約 28 秒／張。

學到的：

- **左右要用畫面方向講**：寫「左手」模型會舉錯手（6/6 全錯），改成 "the hand on the right side of the image" 才對。
- **提示詞要寫明要保留的材質**：不寫的話多數候選把前臂畫成褐色長袖或手過大；明寫「手臂保持銀色板甲、手與另一隻手同大小」並 `--avoid` 布袖、過大的手，才挑得到可用的。
- **命中率低，要多抽再挑**：指向多半變成 V 字或豎食指，敬禮多半連持劍手也動了；24 抽挑 1 是常態。
- 不要貼整塊橢圓區域（v3），會留下灰暈；只貼人物前景像素（v4 起）。
- 貼回區內的肩甲線條是候選版本，只是接近原圖；身體比例和原圖差太多的候選不能用（貼回會看到肩部變形）。

## Demo 3：換劍身材質（靜圖）

**採用**（v5–v6）：SAM3 `track-text` 以 `blue crystal` 取得**整把劍**遮罩、以 `hair` 取得頭髮前景 → 劍身像素依原亮度對應到暗鋼→銀的色階（就地換色，不重畫）→ 劍附近殘留的藍色細邊與被反光染藍的髮梢再中和 → 頭髮前景不動。

數字（v6）：劍附近藍／青像素 32,791 → 238；距劍 30 像素以外 933,016 像素變動 **0**。

被否決的：

| 做法 | 為什麼不用 |
|---|---|
| SDXL `inpaint`／`guided_inpaint` 重畫劍身（v1） | 只把劍身塗成接近背景的灰影，畫不出新材質 |
| FLUX.2 整張重畫再貼回遮罩內（v1–v3） | 範圍外可以做到 0，但接縫處有灰暈、舊輪廓細線；FLUX.2 輸出高度會變（1216→1232），要先縮回才能比 |
| 重畫劍根（v7 幾何重畫、v8 幾何延伸、v9 鏡射主劍筆觸） | **Steve 否決**：劍變形。原圖劍根被頭髮擋住，硬補出來不像同一把劍。結論：原圖本來就畫壞的部位不要靠演算法補，要嘛接受、要嘛請美術改 |

## Demo 4：影片裡換劍材質

**採用**（v10–v11，簡報用 v11）：

1. 來源影片：`video/h3/img2video`（draft，需 `--allow-unverified-platform`）做騎士揮砍，2 個候選挑 1（107 幀、24fps）。
2. SAM3 `track-text` 逐幀追蹤 `blue crystal`（劍刃）與 `hair`。
3. 每幀用和 Demo 3 同一套換色，色階固定取自第 0 幀，避免逐幀亮度跳動。
4. 揮砍光軌（模型自己畫的特效）不用硬遮罩，改用藍／青飽和度算柔邊、只去色保留亮度，避免方塊邊。
5. 清掉小於 120 像素的零碎改動，劍鞘一律還原。

數字（v11）：青藍像素每幀平均 10,225 → 66；劍／光軌影響區以外每幀變動 **0**（107 幀最大 0）。

被否決的：

| 做法 | 為什麼不用 |
|---|---|
| VACE 逐幀重畫（`video/wan-vace/inpaint-reference`，v1–v2） | 會閃；遮罩外沒有做到 0（每幀約 3% 像素差異超過 8 色階，平均 1.4–1.6／255），原因沒查清 |
| 第一幀新劍以仿射變換貼到每幀（v3） | 範圍外 0，但第 48 幀劍尖糊，且來源劍本身在變形，貼上去的剛性劍對不上 |
| `video/wan/img2video`（Wan 2.2 5B）做揮砍來源 | 6 個候選都不是乾淨揮砍（不動、變形、鏡頭亂飛、劍變細） |

學到的：

- SAM3 文字要具體：`sword` 會連劍鞘一起選且第 12 幀丟失，`giant blade` 或 `blue crystal` 才穩。
- 護手 `golden crossguard` 在下劈中段 39 幀追丟；高速動態模糊幀遮罩會吃進整條光帶。追蹤結果要逐段看預覽。
- 「相鄰幀差」不能當穩定度指標：來源劍本身在變形，換色拉大對比後數字反而變大。

剩下的缺點（v11）：第 47–50 幀光軌邊緣仍有淡青白殘影；第 46–47 幀劍身上緣有一段灰色細弧；第 50 幀劍尖有少量深色碎點。

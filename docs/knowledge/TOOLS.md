# 工具與技能總表

只列 repo 目前有原始碼或文件支援的能力狀態與路由。需求整理、ComfyUI 執行、平台原生圖片工具及非生成檔案處理分開選擇；既有完整 brief 直接交接，不必載入整份能力表。可執行不代表該機器已安裝或經實測；本機 ComfyUI 生成前仍依 [art-generation.md](art-generation.md)、影片依 [video/README.md](video/README.md) 核對本機能力快照與證據。

| 能力／入口 | 現況與限制 | 何時讀哪份技能 |
|---|---|---|
| 共用美術工作流程：`skills/game-art-workflow/SKILL.md` | 需求、參考用途、修改／保留項、版本與內容驗收；物件系列／VFX／角色動作按需讀 `references/production.md`。只提供方法，不證明引擎可執行；職責盤點見該技能 `references/responsibilities.md`。 | 先整理需求、跨引擎共用方法或製作規劃時讀；需求已完整不重做 brief。 |
| 平台原生圖片執行：`skills/platform-image-gen/SKILL.md` | 依當下平台圖片工具 schema 檢查輸入與輸出能力；不讀本機 config、不套 ComfyUI 參數、不使用外部付費 API／CLI。2026-10-05 本會話文字生圖／單原圖編修各一張已實測，候選待 Steve 驗收；多參考／其他平台／影片未測，不是新增 backend。 | 使用者選用平台原生圖片工具時讀；影片不適用，工具缺失交回規格並說明阻塞。 |
| ComfyUI 有限參數比較：`skills/comfyui-image-sweep/SKILL.md` | 固定 prompt／seed／來源／參考，最多 16 候選，只包裝四個既有圖片 task。規則與參數 reference 已拆出，CLI 仍是 `image_edit_tools.py sweep`；不新增 graph。 | 使用者明確要求固定輸入的有限參數比較時讀，不能當自動重試。 |
| 圖片生成：`tools_src/generate.py` facade + `tools_src/comfyui_pipeline/` | 現有 12 個圖片 task：`concept`、`flux2_concept`、`flux2_edit`、`icon_asset`、`pose_only`、`style_lock`、`character_action`、`refine`、`inpaint`、`guided_inpaint`、`upscale`、`layer_split`。固定 graph；SDXL/SD1.5 查 image capability/profile；FLUX.2 有獨立 preflight 與實機證據，不套 image profile。不可自行組 graph。 | 本專案預設或選定 ComfyUI 的圖片需求讀 `skills/comfyui-art-gen/SKILL.md`；路由看 [art-generation.md](art-generation.md)。 |
| 遊戲圖片編修需求整理：brief | 本專案相容入口；共用 brief 規則由 `game-art-workflow` 維護，本入口保留 ComfyUI 輸入映射及引擎交接，不執行生成。 | 讀 `skills/game-art-edit-brief/SKILL.md`；實際生成依使用者選定的 ComfyUI／平台圖片執行技能。 |
| 本機圖片編修工具：`tools_src/image_edit_tools.py` | `composite` 以 Alpha 0 選編修圖、255 保留來源，可選 `--keep-source-alpha` 保留來源 Alpha；`recolor` 在既有 Alpha PNG 選區內，僅對可見且符合色相／飽和度條件像素做 HSV hue rotation，保留來源 Alpha 與未匹配 RGBA，不呼叫生成模型或新增紋理；`compare` 產生 RGBA byte 差異及區域統計；`sweep` 規則已由 `comfyui-image-sweep` 獨立維護（實作同檔），固定 prompt/seed/參考，只呼叫 `refine`、`inpaint`、`guided_inpaint`、`character_action`，上限 16 個候選；`reference-board` 產生帶用途標籤的參考圖板（1–12 張）；`asset-audit` 檢查 Alpha 通道／像素統計、可見框、尺寸與碰邊。後兩者只供人工整理及技術觀察，不做語意或美術評分。2026-10-03 單件色相旋轉候選與限制見 [single-object-color.md](art/single-object-color.md)；完整驗證記錄見 [edit-tools.md](art/edit-tools.md)。 | 合成、局部純換色、差異檢視、整理參考圖、透明素材檢查時讀 `skills/local-image-edit-tools/SKILL.md`；有限參數比較讀 `skills/comfyui-image-sweep/SKILL.md`；情境見 `skills/game-art-edit-brief/references/scenarios.md`，驗證狀態見 [edit-tools.md](art/edit-tools.md) 與 [single-object-color.md](art/single-object-color.md)。 |
| 物件與平面素材組裝：`tools_src/comfyui_design.py` + `skills/comfyui-object-design/SKILL.md` | 固定 ComfyUI Core graph：透明物件放入不透明背景（`scene`）、多輸入排檢視表（`sheet`）、重複單一透明圖樣（`pattern`）。不新增圖片 task 或模型；輸出為不透明 RGB。2026-10-03 實機候選與限制見 [object-design-workflows.md](art/object-design-workflows.md)；生成素材仍各自依既有 task gate。 | 物件展示合成、素材檢視表、單圖樣重複時讀 `skills/comfyui-object-design/SKILL.md`；單件生成、局部材質編修仍讀 `skills/comfyui-art-gen/SKILL.md`。 |
| 影片生成與影片本機處理：`generate.py` + PyAV helpers | 7 個生成 task：`img2video`、`fx_loop`、`transition`、`clip_extend`、`character_video`、`camera_move`、`pose_drive`；2 個本機 task：`video_concat`、`video_composite`。影片查 `video_capabilities.json`，concat/composite 不需 ComfyUI server；不得猜 backend 或切換 task。 | 影片需求讀 `skills/comfyui-video-gen/SKILL.md`，規格與能力見 [video/README.md](video/README.md)。 |
| 劇情片本機聲音與 Animatic：`tools_src/film_audio.py` | 獨立 helper，不是 `generate.py` task、無 ComfyUI custom node。提供 SAPI/Piper/Qwen3 TTS、voices/probe、最多 32 軌 mix、靜幀 animatic 與 dub；WAV 48 kHz stereo PCM16、MP4 H.264 24 FPS/AAC，最長 10 分鐘，輸出不覆寫並附 candidate manifest。Serena 與 Uncle_Fu、Animatic/dub 有技術 smoke；聲音內容仍待聽驗。此 helper 本身不做 lipsync。 | 劇情多鏡作品，依 `skills/comfyui-film-workflow/SKILL.md` 先做 TTS 時序再排 storyboard/animatic；工具操作、限制與實測見該技能的 [audio-tools.md](../../skills/comfyui-film-workflow/references/audio-tools.md)。 |
| 本機唇形同步 helper：`tools_src/film_lipsync.py` | 固定 MuseTalk v1.5 與隔離 runtime，不是 `generate.py` task 或 ComfyUI custom node；來源限 24 CFR、最長 30 秒、長邊至多 1280、單一近正面臉部候選，speech 0.5–30 秒且不得長於來源，不循環動作。第二輪固定 helper contract 技術 smoke pass；內容狀態仍 candidate，嘴型自然度及騎士／劇情適用性未驗收。 | 只有需要為合適的單鏡臉部近景候選配台詞時，依 [lipsync-tools.md](../../skills/comfyui-film-workflow/references/lipsync-tools.md) 檢查限制與 runtime；不能推定可用於遠景、多臉或所有影片。 |
| ComfyUI server-side ReActor 影片換臉：`tools_src/face_swap.py` + `tools_src/comfyui_face_swap_video/` | 固定 2-node graph；server 端驗證 local paths、stream-decode、8-frame batches、直接呼叫官方 ReActor node、音訊/媒體輸出與完整驗證。Client 僅 preflight、queue、下載四個成果，不做媒體處理。部署 shared package 到 `tools/` 與 `custom_nodes/comfyui-face-swap-video/`，沿用 generate facade/package。獨立 gate，不新增 `generate.py` task/backend。Smoke-v1/full-v2 完整解碼；技術 warning candidate，未美術驗收。 | 換臉需求讀 `skills/comfyui-face-swap-workflow/SKILL.md`；graph、部署、preflight、結果與 deprecated prototype 見 [local-tool.md](../../skills/comfyui-face-swap-workflow/references/local-tool.md)。 |
| 結果 manifest：`--result-json` | 選用圖片 task manifest，schema v1；只記技術輸出檢查，不代表內容驗收。 | 需要追溯時看 [art-generation.md](art-generation.md) 的結果紀錄小節與技能的 [result-records.md](result-records.md)。 |

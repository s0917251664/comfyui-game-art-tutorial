# --control-type 選擇判斷(canny / pose / depth)

`skills/comfyui-art-gen/SKILL.md` 的 `pose_only`/`character_action` 章節指向這裡——平常用預設 `canny` 就好,只有參考圖比較特殊(人物照片、稀疏線稿、需要控制空間深度)時才需要主動判斷該不該換。

## 三種來源分別適合什麼參考圖

- **`canny`(預設)**:抽取參考圖的像素邊緣,照著邊緣的形狀生成。適合線條完整、細節足夠的線稿/草圖。
- **`pose`**:先跑 OpenPose 抽取人體骨架關鍵點,再照骨架生成,會忽略參考圖的背景/衣服細節,只鎖姿勢。適合「一張人物照片,想照這個人的動作姿勢」,或線稿本身過於簡略(見下方)。
- **`depth`**:抽取參考圖的深度圖,適合要控制的是空間前後景關係,而不是人物姿勢本身。

## 稀疏線稿用 canny 容易失真

`canny` 是把參考圖的像素邊緣直接照抄,**如果線稿過於簡略(例如只有幾條線的簡筆火柴人,缺乏完整輪廓),canny 會把稀疏的線條當成人體的真實邊緣照抄**,模型沒有足夠的邊緣資訊可以重建完整人形,容易生出扭曲變形的結果。

這種情況即使來源在直覺上算是「線稿」,也建議改用 `pose`(推斷關鍵點骨架,不受線條密度影響),或請使用者換一張更完整的參考圖/真人照片。

## 文字描述要跟參考圖的實際動作一致

不管用哪種 `--control-type`,寫 prompt 前先看一眼參考圖實際在做什麼動作。文字描述的動作跟姿勢參考圖衝突時(例如圖是動態格鬥姿勢,文字卻寫靜態站姿),容易生出構圖矛盾的結果——這不是 `--control-type` 選錯,是 prompt 內容本身跟參考圖打架。

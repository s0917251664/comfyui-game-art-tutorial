# ADR：編修結果一律貼回原圖；實驗紀錄只收文字

## 決策

1. **編修只准改指定的地方。** 任何改圖、改姿勢、換材質、影片物件替換，交付前都要把改動區以外貼回原圖，並量「改動區以外變動像素 = 0」。盔甲或色調漂移、多長手腳、遮罩邊緣粗糙、影片閃爍都算不合格（Steve，2026-11-03）。
2. **原圖本來就畫壞的部位，不用演算法硬補。** 劍根重畫三版（幾何重畫、幾何延伸、鏡射筆觸）都讓劍變形而被否決；這類問題交給美術，或接受原狀。
3. **repo 只放決策紀錄與新工具，不放實驗圖片、影片、GIF**（Steve，2026-11-05）。媒體檔留在跑實驗的電腦 `output/`；`.gitignore` 擋下 `docs/experiments/` 內的媒體檔。舊證據圖封存在分支 `claude/project-thread-s1ejng`（PR #12）。

## 依據

- [四個編修 Demo 的決策紀錄](../../experiments/2026-11-03-edit-demos.md)：pose-edit＋貼回、就地換色、影片逐幀換色都做到改動區以外 0；VACE 逐幀重畫做不到且會閃。
- [平台對照](../../experiments/2026-10-19-platform-comparison.md)：「貼回後範圍外 0」是固定流程相對平台最穩的優勢，平台結果也可以用同一張遮罩貼回。

## 影響

- 新的實驗紀錄最後要有「結論複查」，標明每條結論仍有效、已更新或已作廢。
- Demo 裡的 ECC 對位貼回、依亮度換色是一次性腳本，尚未做成 repo 工具；要做時照[新增能力清單](../maintenance/new-capability-checklist.md)。

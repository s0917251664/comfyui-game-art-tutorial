# 封面「Q 版角色雙手舉錘」失敗紀錄（2026-10-14～17）

Slot 破冰獎勵封面：二頭身馬娘 Skye 跳躍、雙手握長柄冰錘準備砸下。嚴格需求：角色、武器、背景與舊封面 v4 一致，只改姿勢與握法。前後約 90 組 ComfyUI 實驗，**至今沒有一張被使用者接受**。這頁記錄哪些做法有效、哪些失敗，供下次預期管理。不是通用生成規則。

本機產物在 `output/cover-redo/`（e1–e84、q1–q7）；逐輪筆記在當時的 side-session notes。output 是本機產物，另機未必存在。

## 最後卡住的地方

**兩隻 Q 版短手同時、清楚地握在一根短握把上。** FLUX.2 Klein 4B 和 Qwen-Image-Edit 2511 都一樣：整張生成時幾乎每張只畫出一隻手；局部重畫時不是手指糊成一團、多出手掌，就是連錘柄一起被改掉、錘頭透視接不上。

## 有效的做法

| 做法 | 證據 |
|---|---|
| 錘子用 3D 定透視，再照設計圖上色，放進版面當參考 | `hammer_proxy.glb`（無三視圖平面）在 Load3D 渲染 → `edit-object-reference-masked` 照設計 3/4 視角上色（q4_paint_777）→ 放進骨架版面；模型照抄版面時錘子造型與透視都正確（q4、q6） |
| 錘子參考要單一視角 | 四視角設計圖會生出多把錘子（e3） |
| 手填 OpenPose 關鍵點＋錘子疊成「版面圖」當 image1 | `RenderPeopleKps` 直接填 dict 關鍵點；雙手握柄首次出現在 e21 |
| 骨架要照母版比例（手臂約 0.6 頭高） | 手臂畫成約 1 頭高時人物變三頭身、手臂過長（e28→e29） |
| 原圖遮掉要改的部位再當參考 | v4 只要露出舊腿，模型就照抄；用灰塊遮掉後才改得動（e40→e41） |
| 角色母版一定要給 | 沒給時服裝走樣、多出緊身褲與怪袖口（q1、q2）；袖口要正面描述「寬袖口疊在手套上」，否定句無效（e23→e24） |
| 讓使用者用 repo 遮罩工具圈範圍 | `python -m tools_src.simple_mask_tool.client create/fetch`，比描述位置準 |

## 失敗的做法

| 做法 | 結果 |
|---|---|
| 只靠文字描述雙手握柄（FLUX.2 Klein 4B） | 一律單手（e5、e6） |
| 寫實照片或公仔照當姿勢參考、轉角度 | 小角度被模型扶正、大角度被照抄成斜躺（e10–e17） |
| SDXL Illustrious＋xinsir union ControlNet（骨架／深度） | 深度圖抄進原圖錯誤；只用骨架時手被拉到胸前抱住錘子；IPAdapter 母版權重 0.6 仍不像角色（e30–e33） |
| Hunyuan3D 重建的錘子 GLB | 三視圖平面被融進網格，錘頭頂多一片金板（e46–e53）；改用幾何拼的 `hammer_proxy.glb` |
| PoseStudio 手模用程式擺手指 | 只能做到「靠在棍上」；繞棍翻轉手腕時手臂扭曲、網格破掉（e80–e82） |
| 3D 手模縮小貼上再重畫 | 縮到 Q 版大小後結構全失、只剩糊塊（e83） |
| 3D 手模當參考圖局部重畫 | 輸出幾乎不變（e84） |
| 先抽人物、手握直棍修好再換錘子 | 手指大小不一、沒有真的包住棍子（e76–e78） |
| 在已修過的圖上反覆局部修 | 一層層接縫，越修越糟；違反「不拿改壞的圖再修」 |
| 換進階模型 Qwen-Image-Edit 2511 | 手指包柄、錘子設計、比例確實改善，但仍只畫一隻手；一張約 7.5 分鐘（q1–q4） |
| 局部重畫時遮罩框到錘柄 | 柄被改成粗木棍，錘頭透視接不上（q5）；必須連錘頭一起框（q6）或完全不框柄 |
| 角色母版與錘子設計拼成同一張參考 | 兩者都變模糊，錘子改抄版面的方塊錘（q3） |

## 目前最接近的候選

`output/cover-redo/q6_33.png`：錘子造型與透視一致、上手包住握把頂端、背景臉服裝與 v4 一致；缺下面那隻手。下一步（使用者同意、尚未執行）是用只框握把下段的遮罩（`q7_mask.png`）補一隻拳頭。另一條路是 AI 做到這裡、雙手交給美術補。

## 帶走的判斷

- 雙手握短柄是這兩個模型的共同弱點，換更大的模型不是保證；先估成本再決定要不要硬做。
- 「3D 定武器透視＋照設計上色」可重複使用，值得之後做成固定 template（照[擴充協議](../maintenance/extension-protocol.md)）。
- 角色用 3D 人偶或手模都沒成功過，不要再當主要路線。
- 局部修要從乾淨的底圖出發，一次只修一塊；修壞就回到上一張乾淨的圖。

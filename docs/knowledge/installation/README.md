# 安裝與模型知識

ComfyUI 產線安裝決策與模型來源的說明。先從[總工具庫](../TOOLS.md)選出這次要用的工具，再依任務讀：

- [開始使用與路線選擇](initialization.md)：新使用者先整理需求與核對工具；只有明確選擇本機能力時才走安裝路線。
- [安裝目標與檢查流程](install-guide.md)：新機器現況盤點、安裝與部署、能力偵測、離線檢查和實機 smoke。
- [模型家族、來源與容量](models-and-sources.md)：模型檔名、下載來源、選配項目與空間估算。
- [LoRA 訓練工具](lora-training.md)：只有使用者要訓練角色或風格 LoRA 時讀。

此知識庫不授權模型升級。版本重現依 [已驗證版本](../../tested-versions.md) 與各機器實際擷取狀態；升級評估是另一個明確觸發的維護工作。Wan Animate 與 SCAIL-2 是獨立的 template 路線，安裝 pin 與歷史測試見[安裝紀錄](../video/wan-animate-install.md)。專案知識庫的維護範圍見 [Obsidian 整合說明](../maintenance/obsidian-integration.md)。

# R5 生成方法停損：同一問題兩輪沒解，就換方法層級

修圖、修動畫時，同一個瑕疵連續兩輪處理後仍在，就不再用同一層級的方法繼續調，改換更上一層的方法，並告訴使用者為什麼換。

## 方法層級（由淺到深）

| 層級 | 例子 |
|---|---|
| 1. 調參數 | 換 seed、改 prompt、調 denoise、加限制描述 |
| 2. 確定性修補 | 用程式換回道具原圖、清殘渣、去背、縮放、調色 |
| 3. 局部重繪 | 遮罩重繪、VACE 局部重繪、接縫修補 |
| 4. 換條件重新生成 | 換參考圖組合、換 task（例如讓模型帶角色與道具參考圖自己擺姿勢）、換起點或終點 |
| 5. 換流程或模型 | 換模型、改成新的節點組合（新組合照 [R2](fixed-graphs.md) 先實驗） |

## 規則

1. **一輪**＝一次處理後檢查（不論是 agent 自檢還是使用者退件）。同一個瑕疵（例如多一隻手、手沒握住、接縫）連續兩輪沒解，下一輪必須換到別的層級，通常往深一層。
2. **同一區域的局部重繪最多一次**：在已修過的地方再補只會越補越糊（[橫向動作經驗](../experiences/side-scroller-character-anim-2026-10.md)）；不行就回到乾淨來源，往第 4 層走。
3. **不回頭用已被否決的底圖或做法**，除非使用者明確要求。
4. **開始前先選最有希望的層級**：角色姿勢、手與道具的關係這類結構問題，優先用第 4 層（模型帶參考圖自己擺姿勢），不從手工合成身體部件開始；道具外觀一律走第 2 層（貼原圖）。
5. **換層級時告訴使用者**：說明前兩輪的失敗點、換成什麼、預期解決什麼；換到第 5 層、要下載模型或安裝節點仍要先取得同意。
6. 停損不等於放棄：所有層級都試過仍做不到時，如實說明目前做不到與剩下的選項，由使用者決定。

## 證據

2026-10-19～21 `skye-ice-hammer-game` 持槌拖錘跑：手工合成手臂、接縫重繪、局部重繪清多出的手，各自連續多輪失敗仍繼續；最後是使用者提議「給參考圖和武器，讓模型自己擺姿勢」才解決。見[持槌拖錘跑返工檢討](../experiences/armed-drag-run-rework-retro-2026-10.md)。

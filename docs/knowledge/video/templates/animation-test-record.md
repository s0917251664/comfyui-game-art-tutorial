# 動畫候選測試紀錄

每個實際輸出候選各建一份紀錄，保留技術結果與內容判斷的區別。未執行的欄位留白或寫「未測」，不得用預設值補成實測值；candidate 不會因技術通過而自動成為 accepted。

## 識別與輸入

- 候選 ID／日期：
- 對應 brief：
- 執行路線及實際 workflow／graph：
- 來源影片／影格版本、路徑與 SHA-256：
- 角色參考版本、路徑與 SHA-256：
- Mask 路徑、SHA-256 與語義說明：
- 輸出影片路徑、SHA-256：
- 抽查影格路徑與時間／frame index：首／中／末：

## 實際生成設定

- ComfyUI 版本、node pins 與執行環境：
- 模型名稱、檔案版本／來源、精度、檔案 hash：
- 正向 prompt（完整原文）：
- 負向 prompt（完整原文或未使用）：
- 解析度：
- 幀數／FPS／時長：
- Steps／CFG／sampler／scheduler：
- Seed：
- 其餘實際輸入與設定：
- 相對基準唯一改動：

## 技術檢查

- Queue／執行狀態：
- 冷啟動／暖機耗時及計時方式：
- GPU 記憶體數值、取樣方式與是否包含其他程序：
- 輸出編碼、尺寸、幀數、FPS／PTS 與完整解碼：
- 音訊狀態：
- 技術檢查結果：pass／fail／部分通過／未測：
- 技術錯誤或限制：

| 位置 | 身份／輪廓 | 服裝／材質／顏色 | 動作連續性 | 手部／接觸 | 遮罩／背景 | 未要求道具或改變 |

| 首幀 |  |  |  |  |  |  |
| 中間幀 |  |  |  |  |  |  |
| 末幀 |  |  |  |  |  |  |

- 跨幀觀察（身份漂移、閃爍、形狀變化等）：
- Brief 條件逐項結果：
- 內容狀態：candidate／其他（須附使用者決定）：

## 比較結論與使用者決定

- 與哪個基準候選比較：
- 本輪唯一變因及觀察到的差異：
- 解讀限制（如 prompt 假說尚未證實、跨模型 seed 不等價）：
- 美術審核者的明確決定及日期：
- 決定理由：
- 後續行動（僅記已決定事項）：

## 來源與追溯

- 原始 validation／manifest／log 路徑：
- 參考的官方文件或固定版本連結：
- 記錄者與補充：

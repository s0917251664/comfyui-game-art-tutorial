# ComfyUI 產線技術盤點

只有使用者明確要求評估、盤點或查找可升級技術時使用。一般裝機、產圖或維護不會觸發此技能。

先從[總工具庫](../../docs/knowledge/TOOLS.md)確認相關能力，再依 [維護知識索引](../../docs/knowledge/maintenance/README.md) 執行；讀 [盤點與評估流程](../../docs/knowledge/maintenance/pipeline-review.md)，並按範圍查 [技術掃描類別](../../docs/knowledge/maintenance/scan-categories.md)。檢查現有產線及其驗證狀態，再查當前一手來源，提出候選、差異、風險與建議，清楚標示未改動任何設定。

此技能只做盤點、研究與建議。不得自行替換模型／設定檔、改取樣參數、下載模型或把候選標為已驗證。只有使用者明確核准具體變更後，才依 [新增能力檢查流程](../../docs/knowledge/maintenance/new-capability-checklist.md) 實作核准項目。
